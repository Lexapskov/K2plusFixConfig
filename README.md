УСТАНОВКА
Открой Вебинтерфейс Fluidd введя "IP адрес принтера":4408/ в строку браузера
В леввой колонке выбери меню со скобочками "Конфигурация"
Добавь туда файл overrides.cfg
Открой файл printer.cfg в конце которого над строчкой
#*# <---------------------- SAVE_CONFIG ---------------------->
вставь строку:
[include overrides.cfg]
Нажми кнопку "Сохранить" (справа вверху)
закрой printer.cfg (крестик слева вверху)
Открой overrides.cfg изучи его комментарии - некоторые пункты (например для ликвидации ошибок принтера после запуска pid и заводских макросов из консоли fluidd) потребуют копирования участков кода вручную
После того как закончишь и сохранишь все изменения открой любой файл.cfg и нажми сохранить и перезагрузить (справа вверху)
Теперь можно печатать и радоваться точному Z-offset снижению числа зажевываний (jamming) и чистому соплу, если не забываешь о калибровке потока для каждого нового филамента, который ты устанавливаешь в свой принтер, т.к. парковка на пружинной пластинке и латунная щетка не спасут от загрязнений при печати с переэкструзией.

АЛЬТЕРНАТИВНЫЙ ПОДХОД Если версия прошивки совпадает
Просто загрузи все файлы конфигурации из данного репозитория с заменой оригинальных (предварительно можно скачать их на комп для бекапа)
открой любой файл.cfg и нажми сохранить и перезагрузить (справа вверху)
при альтернативном подходе ОБЯЗАТЕЛЬНО
подойди к принтеру и с экрана "настройки">"калибровка" запусти "Автовыравнивание" (bed leveling) "Калибровка резца" (cutter calibration) и "Формирование ввода" (INPUTSHAPING)
на компьютере из консоли fluidd запусти макросы NOZZLE_PID и по желанию BEDPID
Теперь можно печатать и радоваться точному Z-offset снижению числа зажевываний (jamming) и чистому соплу если не забываешь о калибровке потока для каждого нового филамента, который ты устанавливаешь в свой принтер, т.к. парковка на пружинной пластинке и латунная щетка не спасут от загрязнений при печати с переэкструзией.

В стартовом G-коде добавьте:
SET_ZOFFSET FIRST_LAYER_HEIGHT=[first_layer_height] FILAMENT_SHRINK=[filament_shrink] NOZZLE_TEMPERATURE_INITIAL_LAYER=[nozzle_temperature_initial_layer]
